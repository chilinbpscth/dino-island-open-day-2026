# 11 科完整遊戲更新：執行及驗收清單

依據使用者 2026-09-08 確認計劃及《Dino Island｜11 科恐龍遊戲 Game Module Planning》。目標為完整遊戲、素材、動畫、語音、提示、離線及正式發布；不可將局部 demo 當完成。

## 已確認決策
- 3–5 歲，iPad 優先，每科約 2–4 分鐘，無強制湊時。
- 保留現有角色、網站、自由園區及導遊導航；保留 Google 後台、排行榜及拍照證書。
- 11 科選 10 科，6 分領證，10 分排名。單科 240 秒上限；地圖、背景、權限及載入等待不計時。
- 不收年齡；數學最多 5，資訊最多 3 步。兩次錯誤提示、三次逐步協助。
- 英文畫面零英文字。英文及體育本機姿態辨識，失敗可轉五秒倒數＋三秒長按親子確認。
- 普通話本機錄音／回播，無發音評分、離頁刪除。姿態影像不錄製／上傳。
- 由 Codex 製作具發布權限的粵、英、普通話聲檔並預載，老師核對發音。缺工具權限須明列。
