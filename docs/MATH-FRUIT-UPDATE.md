# 數學：三種水果餐單

按 2026-09-10 用戶要求，改為認識蘋果、香蕉、士多啤梨，再數清楚每種水果份量。只用一隻被照顧的小龍。

先逐種點選辨認水果；錯選可再試。之後三張餐單分別要求（蘋果／香蕉／士多啤梨）：1／1／1、2／1／3、3／2／1。可自由決定餵食次序，每次拖一件，亦可先點水果再點小龍。每種有獨立數字及圓點，夠數後再餵不計入，不扣分。三種都剛好才可下一張。

同日追加：下方改為三堆水果，各有五件；每成功餵一件，該堆減少一件，下一張餐單補滿。拖動只帶走一件圖示。成功有短促雙音及小龍食水果動作，全部夠數有三音完成聲；超量只有柔和提示，不減水果或扣分。聲效可獨立開關，使用本機 Web Audio，不需網絡。離開／切背景會關閉聲效引擎。`tests/math-feedback-browser.mjs` 驗證堆數、聲音節點啟動、靜音、動畫及清理；觸控拖放／取消測試亦通過。畫面見 `screenshots/math-fruit-piles.png`。

水果圖示為原創 SVG；沿用已批准的小龍和花園。新增六段粵語水果名／餐單語音，更新原玩法介紹；全部本機可離線播放，合成讀音仍可由老師在試聽頁核對。
