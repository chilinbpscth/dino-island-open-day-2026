# 科學站骨架示意及場景

本遊戲以四部分幫幼兒認識頭、身體、腳及尾的位置關係。`hub/modules/fossil-art.js` 為本次自行繪製的簡化向量幾何，骨架、拼圖物件及完成畫面共用同一套線條。它不是任何指定恐龍品種的標本或完整骨骼圖，不能用作骨頭數量／物種鑑定教材。

- 頭朝左、尾在右；頸及脊柱連向身體、腿在身體下方。拼合與完成畫面保持相同位置。
- 頭、身體、腳、尾分成四個互動部分，並非聲稱恐龍只有四塊骨頭。
- 發掘背景由內建 image_gen 製作，沒有描摹博物館／供應商相片；提示：`design/game-assets/science-excavation-prompt.md`。
- 完成以漸現展示原創小龍外形想像，保留「唔係恐龍復活」說明；減少動態效果設定下直接顯示。
- 研究員角色新姿勢及完整教師覆核仍未完成，以上不是整科最終交付聲明。

教學背景核對來源：[Natural History Museum：What can scientists learn about dinosaurs, and how?](https://www.nhm.ac.uk/discover/what-can-scientists-learn-about-dinosaurs-and-how.html)。該館說明重組骨架會運用解剖知識及與其他動物比較；本遊戲只抽取「觀察化石、拼合、推想外形」概念，沒有複製該頁圖像或骨骼線稿。
