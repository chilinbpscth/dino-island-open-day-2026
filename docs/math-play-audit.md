# 數學站試玩檢查｜2026-09-10

實際操作網頁，另以 Chromium 觸控事件模擬 1194×834、1024×768 及 390×844；未代替實體 iPad 驗收。

發現並修正：橫向畫面捲到水果時，小龍上半身離開畫面。遊戲面板的 overflow:hidden 阻止餐單區黏住視窗；只將數學面板改為 overflow:clip，並為水果設定捲動預留位置。現在選水果時小龍仍完整可見，水果及投放位置均可點中。

觸控回歸測試新增：每次拖動前檢查小龍完整位於視窗內，並用命中測試確認水果與小龍沒有被其他元素遮擋。三個尺寸均通過。

其他已通過：15 個獨立水果、所選水果消失及重新開頁保留、超額不計、不消耗水果、取消拖動、三回合計數、聲效與靜音、完成鎖關；50 項單元測試；十科實際介面流程、六站證書、十站排名；預載後離線重開及 11 科路由。
