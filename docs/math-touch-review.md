# 數學站觸控核對 · 2026-09-10

對照用戶 Game Module Planning：數學站以逐份派食物學一一對應，不能只按數字答題。

`node tests/math-touch-browser.mjs` 通過。測試使用 Chromium 的模擬觸控輸入（touchStart、touchMove、touchEnd、touchCancel），不是只用 click 代替拖放：

- 1、3、5 隻逐隻餵食，完成才可進下一回合。
- 拖到目的地但觸控取消，站內數量仍為零，拖動影像清除。
- 再餵已食飽的恐龍不增加數量，也不耗用另一份食物。
- 三次錯誤後能請求發光空碟提示，再正常完成。
- 最後實際顯示完成頁，參加者的數學完成紀錄為真。

限制：這是桌面 Chromium 模擬觸控，尚未驗證 iPad Safari 實機。恐龍朋友素材仍欠，現有多隻同樣小龍不能視為完成角色配置；未用地圖地標替代朋友拖放角色。數量採現有無年齡輸入版本的 1、3、5，不另外收集幼兒年齡。
